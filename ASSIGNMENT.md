# Weather Intelligence Docker Deployment

## 1. Problem Statement

A team has built a Weather Intelligence App in Google AI Studio App Build. The app allows users to search a city, fetch weather data from Open-Meteo, view current weather, see a 7-day forecast, and receive simple planning recommendations. The next step is to convert this AI-generated prototype into a deployable software artifact.
Your task is to download the source code, organize the project, run it locally, Dockerize it, and prove that the Dockerized app runs successfully on your machine.

### Important WSL and Docker Requirement

This assignment must be completed in Ubuntu WSL. Learners must use Node.js, npm, Docker build, and Docker run from inside Ubuntu WSL. Do not run the Docker build or Docker run commands directly from Windows PowerShell or Windows Command Prompt.

### API Information

| API	| Endpoint | Purpose |
|:----|:---------|:--------|
| Open-Meteo | Geocoding API | ``https://geocoding-api.open-meteo.com/v1/search``	| Convert city name into latitude and longitude |
| Open-Meteo | Forecast API	| ``https://api.open-meteo.com/v1/forecast`` | Fetch current weather and 7-day forecast data |

## 3. Learner Tasks

| Step | Task	| Requirement |
|:-----|:-----|:------------|
| 1	| Build the app in Google AI Studio	| Create or reuse the Weather Intelligence App in Google AI Studio App Build. | 
| 2	| Test the app in AI Studio	| Confirm city search, current weather, forecast cards, charts, recommendations, and error states work. | 
| 3	| Download source code | Download/export the source code from Google AI Studio App Build. | 
| 4	| Set up WSL local environment | Open Ubuntu WSL. Install or verify Node.js LTS and npm inside WSL. Capture node -v and npm -v from the WSL terminal. | 
| 5	| Run locally	| From Ubuntu WSL, install dependencies and run the app with npm install and npm run dev. | 
| 6	| Inspect and clean project	| Review package.json, src folder, README, environment files, and unused AI Studio defaults. | 
| 7	| Dockerize the app	| Inside the WSL project folder, create Dockerfile, .dockerignore, and production server configuration such as nginx.conf. | 
| 8	| Build Docker image | From Ubuntu WSL, build the image using docker build. | 
| 9	| Run Docker container locally | From Ubuntu WSL, run the container and open the app in the browser. | 
| 10 | Validate and document | Capture screenshots, WSL commands, test results, and troubleshooting notes. | 
 
(Note: Refer the Help Guide for the guidance: AI-Assisted App Building Help Guide - L2. Refer the WSL and Docker Setup Guidelines before starting local setup.)

## 4. Mandatory Features and Evidence

- Google AI Studio generated app source code is downloaded.
- Project runs locally with Node.js and npm inside Ubuntu WSL.
- Dockerfile is created and builds a production-ready image.
- Docker image is built from inside Ubuntu WSL.
- Docker container is run from inside Ubuntu WSL and serves the app on a browser-accessible port.
- Weather API behavior is validated using at least two valid city searches.
- Invalid city or API error behavior is tested.
- README or help notes include local and Docker run commands for Ubuntu WSL.
- Submission evidence includes screenshots or a short demo recording.

### Google AI Studio Instructions:

Google AI Studio features such as API integration, Secrets, and Publish require Google Cloud access. For this assignment, learners must not use these features.

## 5. Responsible AI and Access Guardrail

Use only public weather data from Open-Meteo. Do not use client data, employee data, customer personal data, private API keys, Gemini API keys, Firebase projects, or GCP billing unless explicitly approved by the program team. For standard completion, Dockerized local deployment inside WSL is sufficient.
